# Aromia Material Library v1

Banco reusable de materias visuales para composiciones editoriales de Aromia.

## Uso

- Los activos son atmosféricos; no son evidencia de producto.
- Nunca sustituyen packshots canónicos ni pueden modificar botella, etiqueta, tapón, logo, color o silueta de un perfume real.
- Preferir composiciones con uno o dos materiales con significado antes que abundancia decorativa.
- Un ingrediente solo puede presentarse como nota de un perfume cuando la provenance del catálogo lo confirma.
- Priorizar transparencia, escala natural, anatomía creíble, textura fotográfica y luz físicamente plausible.

## Gate NO-IA

Rechazar cualquier activo con anatomía imposible, duplicaciones, semillas/pétalos deformes, textura plástica, halos, bordes recortados evidentes, patrones repetitivos o señales generativas que reduzcan la confianza visual.

Los binarios se integran por lotes auditados. `manifest.json` registra categoría, hash, transparencia y función permitida.
