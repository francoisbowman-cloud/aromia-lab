# OMNI — Aromia Front Closure

This branch reconciles the proven visual coherence work with the remaining product, SEO and analytics improvements before catalog expansion.

## Front status represented by this branch

1. **Visual coherence / UX** — typography floor, reduced divider noise, neutral Spanish, responsive targets, quieter hierarchy and integrated BEFORE/AFTER evidence.
2. **Product-image identity** — white product stage, product-only renderer policy and dedicated Acqua di Giò fidelity validation.
3. **Discovery / Quiz / cross-navigation** — local-first personalization plus measurement for note, perfumer, similarity, intention and quiz-progress journeys.
4. **SEO / authorship** — PDP Product structured data preserved; perfumer profiles add canonical metadata and conservative Person JSON-LD using existing reviewed data only.
5. **Analytics / commercial trust** — stable PII-free event contract; tracking remains progressive enhancement and cannot block navigation or purchase.
6. **Material vocabulary** — governed independently in PR #75 so binary/material evolution cannot destabilize the application release.

## Release boundary

A closed front means implementation and automated evidence are ready for review. It does not authorize a production deployment or merge.

## Catalog expansion boundary

The 500-perfume expansion follows this baseline. It must preserve provenance, identity matching, duplicate/variant gates, factual/editorial separation and product-image fidelity. Catalog volume alone is not a success criterion.
